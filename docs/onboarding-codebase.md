## 1. Tổng quan và cách chạy

Ứng dụng quản lý khu trọ, phòng, hồ sơ người thuê, hợp đồng, hóa đơn, khoản thanh toán và ảnh phòng. Bằng chứng: [menu và nhánh hiển thị](../frontend/src/App.jsx#L31), [vai trò](../backend/src/RoomManagement.Domain/UserRoles.cs#L1), [các DbSet](../backend/src/RoomManagement.Data/RoomManagementDbContext.cs#L13).

**Chạy local:** cài .NET SDK 10, SQL Server, Node/npm; tạo `backend/src/RoomManagement.API/appsettings.Local.json` chứa `ConnectionStrings:RoomManagement` và `Jwt:SigningKey` (>=32 byte), hoặc dùng biến `ConnectionStrings__RoomManagement` và `Jwt__SigningKey`. Chạy migration `dotnet ef database update --project backend/src/RoomManagement.Data --startup-project backend/src/RoomManagement.API`; chạy API `dotnet run --project backend/src/RoomManagement.API --launch-profile http`; trong `frontend` chạy `npm install`, `npm run dev` hoặc `npm run build`. Profile HTTP dùng cổng 5185, Vite proxy `/api` tới cổng đó; `VITE_API_BASE_URL` có thể ghi đè URL API. Azure Blob Development mặc định dùng Azurite và container `room-images`; cần chạy Azurite/tạo container cho upload. [README gốc](../README.md#L1), [Data DI](../backend/src/RoomManagement.Data/ServiceCollectionExtensions.cs#L14), [JWT validation](../backend/src/RoomManagement.API/Authentication/AuthenticationExtensions.cs#L12), [launchSettings](../backend/src/RoomManagement.API/Properties/launchSettings.json#L1), [Vite](../frontend/vite.config.js#L1), [.env.example](../frontend/.env.example#L1), [appsettings.Development](../backend/src/RoomManagement.API/appsettings.Development.json#L1).

## 2. Backend

### Kiến trúc và khởi động

Luồng phổ biến: `Controller → Business Service → I*Store → Data Store → RoomManagementDbContext → SQL Server`. API tham chiếu Business và Data để compose DI; Business chỉ phụ thuộc interface store, Data triển khai interface. Đây là mô hình phân tầng với cổng repository, không phải MVC server-rendered. [API csproj](../backend/src/RoomManagement.API/RoomManagement.API.csproj#L4), [Business DI](../backend/src/RoomManagement.Business/ServiceCollectionExtensions.cs#L10), [Data DI](../backend/src/RoomManagement.Data/ServiceCollectionExtensions.cs#L11), [DbContext](../backend/src/RoomManagement.Data/RoomManagementDbContext.cs#L6).

`Program.cs` nạp `appsettings.Local.json` và env vars ở Development; đăng ký DbContext, stores/services, JWT, `AuthenticatedLandlord`, hai hosted worker (`BlobCleanupWorker`, `ContractExpiryWorker`), controller + enum string, exception filter/handler và ProblemDetails. Seed admin ngay khi khởi động rồi chạy `UseExceptionHandler → UseStatusCodePages → UseAuthentication → UseAuthorization → MapControllers`. Không thấy đăng ký CORS, HTTPS redirect hay rate limiter trong pipeline hiện tại. Logging dùng `ILogger` và mức trong appsettings. [Program.cs](../backend/src/RoomManagement.API/Program.cs#L13), [auth DI](../backend/src/RoomManagement.API/Authentication/AuthenticationExtensions.cs#L10), [appsettings](../backend/src/RoomManagement.API/appsettings.json#L1).
